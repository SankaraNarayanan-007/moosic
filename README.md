# 🎵 MOOSIC

> **Ultra Premium Audio Experience**

MOOSIC is a modern web-based music player designed with a **glassmorphism UI**, interactive music controls, user authentication screens, trending music discovery, liked songs, search, and profile customization.

The project focuses on creating a visually immersive and responsive music-streaming-style interface using **HTML, CSS, and JavaScript**.

## ✨ Features

* 🔐 **User Authentication UI**

  * Sign in
  * Create account
  * Username, email and password fields
  * Logout functionality

* 🎧 **Music Player**

  * Play / pause
  * Previous / next track
  * Seek through songs
  * Current and total duration display
  * Dynamic waveform canvas

* 🔎 **Music Search**

  * Search interface for discovering songs
  * Dynamic search interaction

* 🔥 **Trending Music**

  * Dedicated trending music section
  * Global trending music interface

* ❤️ **Liked Songs**

  * Dedicated liked songs section

* 👤 **Profile**

  * Editable username
  * Email display
  * Profile picture upload
  * Audio quality settings
  * Visualizer style settings

* 🎨 **Premium Glassmorphism UI**

  * Glass-card components
  * Mesh gradient background
  * Modern dashboard layout
  * Font Awesome icons

## 🛠️ Technologies Used

| Technology       | Purpose                            |
| ---------------- | ---------------------------------- |
| HTML5            | Application structure              |
| CSS3             | Styling and glassmorphism UI       |
| JavaScript       | Application logic and interactions |

## 🎯 Main Sections

### 🏠 Home

The home dashboard provides the main music discovery area along with the integrated music player.

### 🔥 Trending

Displays the global trending music section for discovering popular tracks.

### ❤️ Liked Songs

Provides a dedicated section for songs marked as liked.

### 👤 Profile

Users can customize their profile by changing their username and uploading a profile image.

### 🎵 Music Player

The player includes:

* Previous track
* Play / pause
* Next track
* Progress control
* Current playback time
* Total track duration
* Waveform visualization

## 🎨 Design

MOOSIC uses a **glassmorphism-inspired interface** with:

* Transparent glass cards
* Mesh gradient background
* Rounded UI components
* Minimal navigation
* Modern typography
* Accent-based interactive elements

The goal is to provide a premium music-player experience while keeping the interface clean and intuitive.
